# 网页、模型与交付

仅在用户任务包含网页或交付时使用。本地预览、Docker 打包、上传 GitHub Release／镜像仓库、更新服务器是不同交付动作；沿用本次会话已明确的授权范围。

## 复用网页结构

现有四川项目采用 Vite＋TypeScript＋OpenSeadragon＋Three.js，无数据库。高清图集为入口，三维按需加载；增加地区配置和独立资产，不为新地貌重写整站。参考工作区的 `docs/web_asset_contract.md` 与现有区域 schema，保持旧链接兼容。

地区配置包含名称、说明、图集／模型 manifest、视角、可选高程倍数、默认值、模型坐标中的旋转中心，以及可选体素参数。标明艺术轮廓、源分辨率、显示格距与示意元素；不要把局部高清图片入口伪装成独立三维场景。

图集生成缩略图、可直接显示的预览、完整图片和 Deep Zoom 瓦片。现有工具使用 512 像素瓦片、1 像素重叠；验收各级范围、文件清单与边缘瓦片尺寸，避免只测最高级。DZI 出错时仍展示预览并可下载原图。

## 模型合同

- 使用稳定的投影原点与单位。当前项目为局部千米、Y 向上：`x=east/1000, y=height/1000, z=-north/1000`；先减记录的平面原点，避免重复偏移。
- 导出 canonical 1 倍几何。网页统一应用高程倍数，旋转中心、贴地地名和水系跟随同一规则；源模型已量化时 1 倍仍称量化地形原比例。
- 平滑模型可以使用真实影像纹理；体素模型可用有限色板顶点色，正确处理 sRGB／线性颜色。没有纹理的顶点色模型不得在元数据中写成“4K 纹理”。
- 通过 glTF／Meshopt 等现有解码链压缩，检查浏览器可用的解码器路径。几何角色区分地形、水面、装饰、底座；可拾取表面与遮挡表面按用途选择，避免点击装饰把旋转中心跳到树顶。
- 桌面约 50 万、移动端约 15 万三角形是现有起始预算，包含地形、水面、底座、装饰全部内容，最终以实测为准。不要只统计地形面。

LOD 候选采用基础网格整数倍；保留正式边界和核心保护区，选择满足预算的最细档，先减装饰。两档标签／水系重新贴合实际解码后的表面。用 GLB 重新解码检查范围、高程、角色、有效掩膜、保护区、法线及三角数，不能只验证导出前数组。

## 状态和交互

分享链接继续保存 `area,view,mode,height,labels,pos,target`；兼容无 `area` 的旧四川链接和小数倍数。地区切换保留浏览模式，重置为新地区默认视角／倍数，释放旧几何、材质、纹理与监听。使用请求代次或取消机制，防止旧地区延迟请求覆盖当前地区。

若任务要求固定绕地貌主角旋转，以已核对地物位置设置中心，视角切换围绕它计算；普通缩放、平移、复位和分享恢复保持预期。相机适配实际几何范围，不能因为更换中心把主体裁掉。

地名面向屏幕，做山体遮挡与文字重叠检测；提供开关。GLB／WebGL 失败时回退图集，模式切换后只留一套有效渲染循环。风格专用的背景、色调映射和灯光按区域实例化，避免改变旧地区的外观。

验证预设视角、拖动与复位、快速连续区域切换、旧请求延迟到达、旧链接／分享链接恢复、图集瓦片加载，以及断开模型／DZI 后的回退。窄屏布局检查溢出和控制按钮；触摸模拟不可用时如实记录，不能写成已测试双指操作。

## 性能记录

本机在常用窗口测约 30 秒旋转，记录浏览器、GPU、窗口／画布尺寸、像素比、模型档位、平均 FPS 与帧时间分位数。目标可沿用约 30 FPS。低帧率降档时保留相机，并注明发生次数及前后档位；不得把降档后的成绩归给较细档。

真机手机 GPU 和模拟移动布局分别记录。测试工具设置了视口、网络阻断、设备仿真时，结束后恢复。无需为一次局部内容变更重跑无关的所有设备测试。

## 静态包与 Docker

网页源码与大展示资源分开：原始 GIS、Blender 场景、渲染中间文件不进入源码仓库；展示资源按当前项目约定进入独立 ZIP／Release，并可包含在完整镜像中。优先复用现有多阶段 Dockerfile、Nginx 路由和资源解包器。

在隔离的源码快照中解包资源，核对清单与 SHA-256，再运行构建和当前必要测试。运行时只需静态服务器与站点，包含 healthz、正确 MIME、缓存策略；缺失 GLB／瓦片不能被 SPA 回退伪装成成功 HTML。验收已有区域与新增区域的 HTTP 资源。

Docker 交付时用当前平台构建、运行并 HTTP 检查；需要离线包则 `save`／压缩／`load` 后核对镜像 ID。Windows 子进程读含中文的 Docker 元数据时明确 UTF-8。基础镜像网络或凭据失败要按实际错误处理，不自动修改全局代理／登录设置。

本地候选资源的 lock 与已发布 lock 分开，候选标明 `local-unpublished`，不写不存在的 Release URL。只有实际上传成功并核对下载哈希后才更新发布锁。打包刷新后重算校验和，清单不递归包含自身；为每种交付给出实际产物路径、启动方式和仍未验证的限制。
