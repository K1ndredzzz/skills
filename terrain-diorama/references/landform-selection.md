# 范围、轮廓与地貌选型

## 通用选择方法

先用现有 DEM 的阴影、坡度／等高线和水系做低成本俯视草图，核对地名坐标及数据覆盖，再选范围。用户未指定精确地点时，从已有可靠地物位置推导；无法确认的坐标保留待定，不直接进入正式建模。

范围要装下“地貌主角＋解释它的周边”：峡谷需要两侧山体和谷底，汇口需要来水与出水方向，临江崖需要崖顶、崖脚和相邻江面。不要为了覆盖一个行政区而缩小核心地物在画面中的比例。如果两个主角在同一取景中太小，采用总览加局部，而非无限扩大单个模型。

先在小图上检查核心轮廓是否可读。关键横向特征若不足约 3–4 个显示网格，很容易在体素化和降档后消失；优先缩小范围或选更合适的网格。这个数字是显示启发式，不是测绘精度保证。垂直量化也要给关键高差留下数个台阶；自然地势已经鲜明时从 1 倍或轻度夸张试起。

| 参数 | 选择依据 | 应记录的实际结果 |
|---|---|---|
| 取景框 | 核心地貌与上下游／外围背景 | 经度纬度范围、投影后宽高 |
| 展示轮廓 | 地形关系、核心余量、构图 | GeoJSON、CRS、哈希、栅格化规则 |
| 水平网格 | 原始有效细节、关键宽度、面数 | 基础格距、边缘／内部格距 |
| 垂直台阶 | 关键高差、体素视觉节奏 | 步长、舍入和基准面、误差 |
| 高程倍数 | 地形可读性与失真程度 | 静态倍数、网页可选倍数 |
| 旋转中心 | 地貌观看重心 | 经度纬度、模型坐标和高程 |
| 镜头 | 要解释的地理关系、遮挡 | 方位角、俯视角、正交范围／焦距 |

外轮廓可以顺山脊或谷肩收束、向河流下游展开，保持有节奏的不对称。它仍是展示裁切，不应被命名为地貌学边界。检查连通分量、细颈、孔洞、主峰与核心地物到边缘距离。通常一块连续沙盘易读，但真实岛屿／必要孔洞可保留；不要把都江堰的“单面、无孔、600 米细颈”等项目数值变成普遍要求。

## 大瓦山与金口大峡谷：台地与深切河谷

先核对目标台地、崖缘、谷底和河道的位置及相互距离，再决定一个组合场景还是两个关联场景。不要照搬都江堰的扇形取景。

- 主角是顶部形态、边缘陡变及谷底的高差关系。轮廓尽量放在次要外围山体上，给顶缘、崖脚和两岸留背景，避免裁切墙被误读为真实峡壁。
- 第一镜头选择能同时看到台地顶面和谷底的方向。可从约 30–45° 斜视试构图，再补 60–75° 高位图解释顶部形态；方位依据实地 DEM 遮挡选择，不固定东南。
- 保护顶缘转折、山脊、峡谷两岸和源河道。降档要检查谷底是否闭合、台地是否被磨成圆包、顶缘是否塌缩。
- 有自然强烈起伏时先试较低夸张；高倍数可能把台地变成尖塔。河水沿源河道和地势变化，不把整个峡谷水面处理成一个平面。
- DEM 高度场适合山体大形，无法复原悬挑、洞穴和垂直岩壁的全部结构。只有用户要求该尺度且资料足够时才增加独立崖壁网格或补充数据。

## 乐山三江汇流：河道拓扑与山水关系

核对岷江、大渡河、青衣江的源数据、名称及汇入顺序。尊重实际多个汇入位置，不能为了“三江”字样把河道都拉到一个虚构三岔点。

- 范围要让来水河段、汇入口、下游出口及相邻岸地同时可读；轮廓沿外围地形收束，不在汇口中央截断。
- 以约 45–70° 高位镜头解释河网，较低斜视补充临江山体关系。旋转中心可选经核对的主汇流区构图重心，不直接用城市中心。
- 保护主河道、真实洲滩、岸线和汇流连接。对每条源河段核对连通及上下游关系，不要求所有水面像元属于同一个连通分量。
- 水面颜色可适度区分来水，但不能将未经观测的颜色差异说成长期真实水质。影像水位和 DEM 日期不同造成的岸线偏差需在记录中解释。
- 窄支流不足显示格宽时，可以采用有记录的制图加宽或保留线叠加；不能把加宽值当成实测河宽。

## 丹霞临江崖：崖壁与江面的横向展开

“丹霞临江崖”尚不是确定地点。新任务中先确认具体崖段；命名为丹霞或说明岩性时，依据用户给定来源或核实的地质资料，不由红色影像自动推断地质成因。

- 让崖顶、陡壁转折、崖脚和江面形成完整关系。沿江适度拉长范围，轮廓在外围缓坡／山脊收边，不剪成等宽长方块。
- 主镜头从能看到崖壁的一侧斜望，约 25–40° 可作为起点；高位补图交代崖段与河道的走向。检查前景山体遮挡，必要时换方位而不是删除挡住的真实山体。
- 保护崖顶折线、崖脚、突出岩体及河岸。较大的垂直台阶会把薄崖台完全吞掉；过粗水平网格会把陡壁变成普通斜坡。
- 配色参考已有影像，适度强化岩面与植被的对比；没有资料时不绘制看似真实的规则地层条带。底座切面使用可区分的示意材质。
- 若目标是近看岩壁裂隙、悬挑或建筑，先评估点云、摄影测量或更细实测地形是否必要。30 米高程仍可做区域地理沙盘，不能承诺该级细节。

## 风格与装饰

像素／体素风优先采用有限色板、硬法线、量化台阶和少量尺度一致的装饰。自然色与暖色可在同一相机、几何和光照下比较，再冻结选择；不必每次都输出两套全量成果。

树、房屋、道路符号和底座切面若为示意，分离对象角色并注明。随机布局使用保存的种子；不在真实水面、无效像元、关键崖缘和核心地貌上散布装饰。不凭想象补画水工设施、寺庙、真实建筑或地质断面。
